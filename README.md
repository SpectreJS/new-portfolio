# Alex Verdier — Creative Developer Portfolio

Immersive editorial portfolio built with React + Vite, SCSS, GSAP (ScrollTrigger, SplitText, Draggable), Lenis and Three.js.

## Run locally
```
npm install
npm run dev
npm run build
```

All copy lives in `src/data/content.js`. Images are in `public/img` and served through the Netlify Image CDN in production.
